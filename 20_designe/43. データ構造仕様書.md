# **Holy Grail Controller データ構造仕様書**

## **1.概要**
システム全体で使用するデータ構造を定義する。  

### **1.1. 名前空間**
Holy Grail Controller を意味する hgc を名前空間にする。  
すべてこの中に置く。  

## **2. 広く使用する定義**
### **2.1. 日時の型**
dateTime

|---|---|---|
|year|ushort|年|
|month|ushort|月|
|day|ushort|日|
|hour|ushort|時|
|min|ushort|分|
|sec|ushort|秒|


## **3. 撮影制御方法**
撮影制御方法はファイル、通信時はjson形式とする。  
ソフトウェア内部で参照するときは構造体として扱う。  
撮影制御方法には以下がある。  
- 夜間撮影
- 太陽直接撮影(朝)
- 太陽直接撮影(夕)
- 日中
- 月の影響の対処

撮影制御方法は Capture Controll Method の略で ccm をキーワードとする。  
### **3.1. 共通の定義**
#### **3.1.1. 露出設定**
■iso感度、シャッター速度、F値の三つ組。  
撮影制御方法の露出設定や限界値の指定に使用する。  
exposure  
jsonと構造体のメンバーを同じ名前とする。  
|名前|型|説明|
|---|---|---|
|iso|ushort|iso感度|
|ss|double|シャッター速度|
|fn|double|F値|

#### **3.1.2. 露出設定項目**
■露出設定を変更する優先度を表す項目。  
enum class で持つ。値は規定しない。変わっても良い。  
exposureType  
|名前|値|説明|
|---|---|---|
|iso|0～|iso感度|
|ss|0～|シャッター速度|
|fn|0～|F値|

#### **3.1.3. 撮影制御方法を区別する名称**
■撮影制御方法を区別する名称。  
ccmType
enum class で持つのが良い。  
値は0は無効、それ以外は意味のある数値とする。  
enum なので規定しない。変わっても良い。  
|名前|値|説明|
|---|---|---|
|invalid|0|無効|
|night|1～|夜間撮影|
|sunrise|1～|太陽直接撮影(朝)|
|sunset|1～|太陽直接撮影(夕)|
|day|1～|日中|
|moon|1～|月の影響への対処|

#### **3.1.4. 撮影制御方法の基本クラス**
すべての撮影制御方法は ccmBase からの派生とする。  
露出設定（iso/ss/fn）の明暗限界と優先度はすべての撮影制御方法が保持するため基本クラスに持つ。  
固定露出など限界を使用しない撮影制御方法でも保持する。  
|名前|型|説明|
|---|---|---|
|ccmType|ccmType|撮影制御方法を区別する名称|
|name|string|ユーザーが定義した名称|
|color|ulong|RGBの色|
|limitBright|exposure|露出設定の明るい側の限界（iso/ss/fn 上限）|
|limitDark|exposure|露出設定の暗い側の限界（iso/ss/fn 下限）|
|priority|exposureType[3]|露出設定を変更する優先度（上位から変更）|

### **3.2. 夜間撮影**
ccmNight  
ccmBase からの派生。  
固定露出のため limitBright と limitDark に同じ値（固定露出値）を設定する。  
出荷時設定の固定露出値は iso=1600、ss=8、fn=1.4 とする。  
jsonと構造体のメンバーを同じ名前とする。  
固有のメンバーを以下に示す。  
|名前|型|出荷時設定|説明|
|---|---|---|---|
|sunAltitude|double|-18.0|開始終了の太陽高度。単位10進数の「°」|
|autoEdge|bool|true|開始終了の自動判別をおこなう|

### **3.3. 朝日撮影**
ccmSunrise  
ccmBase からの派生。  
日の出時刻に太陽を直接撮影するための撮影制御方法。自動露出でおこなう。  
露出設定の明暗限界と優先度は基本クラス（limitBright/limitDark/priority）を使用する。  
jsonと構造体のメンバーを同じ名前とする。  
固有のメンバーを以下に示す。  
|名前|型|出荷時設定|説明|
|---|---|---|---|
|sunAltitude|double|-6.0|薄明の状態を表す太陽高度。単位10進数の「°」|
|ev|double|-3.0|露出補正。範囲 -5.0～+5.0、1/3刻み|

### **3.4. 夕日撮影**
ccmSunset  
ccmBase からの派生。  
夕日を直接撮影するための撮影制御方法。  
薄明の時系列が「朝日撮影」と逆になるだけで構成は同等とする。  
メンバーは「朝日撮影(ccmSunrise)」と同じ。  
|名前|型|出荷時設定|説明|
|---|---|---|---|
|sunAltitude|double|-6.0|薄明の状態を表す太陽高度。単位10進数の「°」|
|ev|double|-3.0|露出補正。範囲 -5.0～+5.0、1/3刻み|

### **3.5. 日中撮影**
ccmDay  
ccmBase からの派生。  
日中の自動露出でおこなう撮影制御方法。  
露出設定の明暗限界と優先度は基本クラスを使用する。  
jsonと構造体のメンバーを同じ名前とする。  
固有のメンバーを以下に示す。  
|名前|型|出荷時設定|説明|
|---|---|---|---|
|ev|double|0.0|露出補正。初期値は±0|

### **3.6. 月の影響への対処**
ccmMoon  
ccmBase からの派生。  
夜間撮影中に月が画角に入る、もしくは近くにある場合の露出設定への対処を定義する。  
時間帯によって挿入されるものではない。  
露出設定の明暗限界と優先度は基本クラスを使用する。  

#### **3.6.1. 対処方法の種別**
moonMode  
enum class で持つ。値は規定しない。変わっても良い。  
|名前|値|説明|
|---|---|---|
|none|0～|補正しない|
|autoBrightness|0～|画角全体の明るさで自動補正をする|
|moonExposure|0～|月自体を撮影する目的で月に露出を合わせる|

#### **3.6.2. 月の影響への対処**
jsonと構造体のメンバーを同じ名前とする。  
固有のメンバーを以下に示す。  
|名前|型|出荷時設定|説明|
|---|---|---|---|
|mode|moonMode|none|対処方法の種別|
|startLuminance|double|0.0|自動補正を開始する撮影対象の輝度。範囲 0～+3ev（autoBrightness 用）|
|ev|double|0.0|目標の露出補正。範囲 0～-10ev（autoBrightness 用）|
|initialExposure|exposure|―|開始時露出設定（moonExposure 用）|
|atmosphericExtinction|bool|false|大気消光補正をおこなう（moonExposure 用）|
|extinctionCoef|double|0.2|大気消光係数。範囲 0.1～0.6|
|geocentricCorrection|bool|false|地心距離補正をおこなう（moonExposure 用）|
|skyBrightnessCoef|double|100|月周辺の空の明るさ補正の係数。範囲 0～100[%]|

#### **3.6.3. 月の影響への対処の初期値**
月を撮影する目的の露出設定（H-G関数）の初期値を定める。  
moonExposureCurve  
|名前|型|出荷時設定|説明|
|---|---|---|---|
|fullMoonMag|double|-12.7|満月の最も明るい瞬間の等級|
|nightLineAge|double|―|夜間撮影線の月齢|
|nightLineMag|double|―|夜間撮影線の等級|

## **4. 撮影計画**
Capture Schedule の略で cs。  
撮影計画を通信やファイル保存で使用する際はjsonとする。  

### **4.1 定義**
撮影計画のスケジュールに入れるイベント。  
enum で取るので値は何でもよい。  
コーディングの状態で変動しても差し支えない。  
無効、だけは 0 とする。  
csEvent  
|名前|値|説明|
|---|---|---|
|invalid|0|無効|
|start|1～|開始|
|sunset|1～|日の入り|
|civilDusk|1～|市民薄明の終わり|
|nauticalDusk|1～|航海薄明の終わり|
|astronomicalDusk|1～|天文薄明の終わり|
|astronomicalDawn|1～|天文薄明の始まり|
|nauticalDawn|1～|航海薄明の始まり|
|civilDawn|1～|市民薄明の始まり|
|sunrise|1～|日の出|
|moonrise|1～|月の出|
|moonset|1～|月の入り|
|end|1～|終了|

### **4.2 イベント**
構造体のメンバーとjsonのkeyは同じ名称を使う。  
イベントの配列。
撮影開始から終了までのイベントを時系列で保存する。  
events
|名前|型|説明|
|---|---|---|
|event|csEvent|時系列なcsEvent|
|when|dateTime|イベント発生時刻|

### **4.3 撮影制御方法**
時間帯に応じた撮影制御方法を定める。  
ccmList
|名前|型|説明|
|---|---|---|
|start|dateTime|撮影制御方法の適用開始時刻|
|end|dateTime|撮影制御方法の適用終了時刻|
|ccm|ccmBase*|撮影制御方法|

## **6. エッジ端末との通信**
### **6.1 基本的なデータ形式**
エッジ端末との通信に使用するデータ形式なのでEdge Terminal Paketの略でetpを略号とする。  
#### **6.1.1 パケット書式**
数値のデータはリトルエンディアンとする。  
|名前|型|値|説明|
|---|---|---|---|
|header|ushort|0x8080|ヘッダ|
|cmd|ushort|可変|コマンドコード|
|method|ushort|可変|ヘッダ|
|length|ulong|可変|dataの長さ。0も可。4の整数倍|
|data|可変|可変|必要に応じたデータ|
|terminal|ulong|0x01234567|終端コード|
|sum|ulong|可変|headerからの4バイトごとの2の補数|

#### **6.1.2 method**
「[パケット書式](#611-パケット書式)」の method の値。  

etpMethod  
|名前|値|説明|  
|---|---|---|
|get|1|データの取得の要求|
|put|2|データを設定する|
|post|3|動作の要求|
|delete|4|削除の要求|
|ack|100|成功の応答|
|nak|200|失敗の応答|

#### **6.1.3 cmd**
「[パケット書式](#611-パケット書式)」の cmd の値。  
etpCmd
|名前|値|説明|  
|---|---|---|
|search|1000|検索|
|action|1|撮影開始|
|stop|2|撮影停止|
|progress|3|撮影中の進捗|
|direction|4|方位、仰角|
|capturePlan|5|撮影計画|
|controlMethod|6|撮影制御方法|
