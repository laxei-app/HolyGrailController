## milkyway_gal_4096.jpg

撮影シミュレーションの背景（全天）。

| | |
|---|---|
| 出典 | ESO「The Milky Way panorama」(eso0932a) |
| 撮影 | Serge Brunier（2008年8月〜2009年2月、ラ・シヤ／パラナルほか） |
| ライセンス | **CC BY 4.0** |
| 表記 | **`ESO/S. Brunier`**（文言を変えず、読める形で） |
| 元 | 6000×3000（ESO 公開の large JPEG） |
| 同梱 | **4096×2048 / JPEG q82 / 約1.9MB**（LANCZOS 縮小） |
| 投影 | **正距円筒（plate carrée）／銀河座標／2:1** |
| 並び | 左端 l=180°、中央 l=0°（銀河中心）、右端 l=−180°。上端 b=+90° |

約1200枚の実写合成。**絵ではなく写真**なので、カメラで実際に写るものと一致する。

**投影方式について**: Wikimedia Commons は Aitoff に分類しているが**誤り**。
実ファイルを確かめたところ四隅まで星で埋まっており（四隅の画素は 6〜8 で、
楕円マスクの黒ではない）、2:1 の正距円筒である。

**差し替えるとき**は投影と座標系を必ず確認すること。ここが違うと星の位置と
背景がずれる（ずれても絵としては成立してしまうので気づきにくい）。

元データ: https://www.eso.org/public/images/eso0932a/
