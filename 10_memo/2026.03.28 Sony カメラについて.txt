◎Init Command Request
　PTPIP の標準機能なので SONY のマニュアルに書いていない。
　ISO 15740 に仕様が規定されているとの事。
　古い PIMA-15740(2000)には載っていない。
　仕様を買わないと見れない様。4.5万円するんだけど…。

■SSH
　TLS 通信をするような機器の場合、SSH でカメラのOS(LINUX)に
　アクセスして証明書の設定などをやるそう。通常は不要。
　TLS を使うハイエンド機で使うかも。対応必要なのかいまいちわからん。

■コマンド送り先
　TCP 15740 決まっている様。
　canon は http で ipアドレス自体がコマンドだったが
　sony は TCP でパケットを送る。

■イベント
　イベントは2019年以降のカメラは確実に使えるがそれ以前の物では
　不正確なので古いカメラも対象とするイニシエーターは使うべきではない。

■live view の画像の取得方法
・dd.xmlの <X_ScalarWebAPI_LiveView_URL> かな？
・GetObject(ObjectHandle=0xFFFFC002)で取得する
・GetObjectInfo(ObjectHandle=0xFFFFC002)で Live View Status(0xD221) が enable になるのを待つ。

◎live view 取得、PIMA15740 の説明
・0x1007 GetObjectHandles:pull でハンドルを取得する。
・0x1008 GetObjectInfo:pull でハンドルを指定して情報を得る
・0x1009 GetObject:pull でハンドルを指定して画像データを得る

◎Camera Controll PTP 2(sony) の説明
・初期化で live view status を有効にしておく
・0xD215 Shooting File Info で 0x8001 以上の場合 GetObjectInfo/GetObject を使える。
・0x1009 GetObject で ObjectHandle を 0xFFFFC001 にすると Capture Image を取得できる。

◎GetObjectInfo で得られる情報(PIMA15740-2000 P.18 Table 8: ObjectInfo Dataset)
・フォーマット
・読み取り専用か否か
・Thumbnail の縦横サイズ、データサイズ
・Image の縦横サイズ、1pix のビット数
・ファイル名、日付、キーワード
