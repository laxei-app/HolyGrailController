2026.07.07 R100 と R10 の撮影周期性能差（＝撮影周期を早められるかの検討材料）

■目的
EOS R100 と EOS R10 でカメラ由来の性能差があるかを実機計測。
撮影周期をどこまで短くできるかの判断材料にする。

■計測条件
- エッジ端末(Edje00)で撮影、撮影周期15秒、各18〜19コマ。
- 同一計画(SIGMA 12mm/センサ22.3x15)でカメラだけ R100→R10 に切替。
- SHOTログの sh=（シャッター投下の壁時計ms）/ tm0= / rdy=(rdyMetering) / set=(露出PUT) を解析。
- offset = (周期 - 最大ss) × 0.7 = (15 - 8)×0.7 = 4899ms（最大ss=夜間ss=8s）。

■結果（平均、括弧は min〜max）
                 R100               R10                差
 rdyMetering    169ms(125-213)     1278ms(452-2612)   R10が約7.6倍・大きく変動
 tm0合計        294ms(181-374)     2416ms(1708-3828)  R10が約8倍
 set(露出PUT)   79ms(0-147)        24ms(ほぼ0)         同等（R10は露出変化少で0多め）
 実周期(sh=)    15.000s σ=0.000    15.000s σ≈0        両方ピッタリ
                (15.000-15.001)    (末尾1コマのみ停止で切れ)

■分析
1. カメラ性能差は実在。R10 はライブビュー取得(rdyMetering)が R100 の7〜8倍遅く、
   0.45〜2.6秒と大きく揺れる。R100 は0.17秒前後で安定。
2. それでも周期は両方15.000秒ピッタリ。タイマ方式(tm0/tm1)の狙い通りで、
   tm0 が offset(4899ms)内に収まる限り、周期は絶対境界にアンカーされ正確。
   R10 の tm0 最大3828ms < offset 4899ms なので、遅くても間に合っている。
3. ただし R10 は余裕が薄い（残り約1.1秒）。ここが周期短縮のボトルネック。

■撮影周期を早める観点での含意（重要）
- offset = (周期 - 最大ss) × 0.7。周期を縮めると offset も縮む。
- 最小周期10秒だと offset = (10-8)×0.7 = 1.4秒。R10 の tm0(最大3.8秒)はこれを超えるので、
  R10 は10秒周期だと周期が崩れる（シャッターが境界に間に合わず遅延/ばらつき）。
  R100(tm0 0.37秒)は問題なし。
- R10 が正確周期を保てる下限 ≒ 最大ss + tm0/0.7 ≒ 8 + 3.8/0.7 ≒ 13.4秒。
  （偶然だが表示の NPF 13.4秒と近い。R10 は実質13.4秒未満は苦しい）
- つまり「周期を早められるか」は カメラの tm0(特に rdyMetering) 次第。
  R100級なら大幅短縮可、R10級は 最大ss + 余裕 が下限。

■撮影周期を早めるための打ち手候補（検討用）
1. 速いカメラを使う（R100級）。rdyMeteringが速いほど offset を小さくでき周期を詰められる。
2. 最大ss(夜間ss)を下げる → offset予算が増える。ただし最長露光が要る夜間で制約。
3. offset係数(0.7)を上げる → シャッターは周期の後方へ寄るが tm0余裕は増える。
   ただし offset + 最大ss < 周期 の制約。
4. tm0そのものを削る:
   - R10 の律速は rdyMetering(平均1.3s・最大2.6s)。ライブビュー取得の頻度/解像度を落とす、
     もしくは測光を毎コマせず間引く（露出が安定している間は測光スキップ）等。
   - 露出PUT(set)は変化分のみで既に軽い(0〜0.3s)。ここは効かない。
5. カメラ実測に基づく最小周期ガード（未実装・提案）:
   現状の最小周期は ss(NPF)ベースで tm0 を考慮していない。数コマの実測 tm0 から
   「tm0 < offset を満たす最小周期」を動的に決めれば、遅いカメラで周期が崩れるのを自動で防げる。
   → 遅いカメラは自動で最小周期が長めにガードされ、速いカメラは短い周期を許可できる。

■結論
- 周期精度リアーキは両カメラで完成・正確(15.000s)。
- カメラ性能差は実在（R10の測光が7〜8倍遅い）が、15秒では offset が吸収。
- 「撮影周期を早める」なら R10 が律速。R10 は概ね13.4秒未満は苦しい、R100は大幅短縮余地あり。
