# 2026.09.02 postNight(夜間後移行)の輝度変動

2026-09-02 朝の通し(R10・スマホ直結)の実画像から、postNight 区間のコマ間の
明るさの安定性を調べた記録。**結論: 前日夕方の preNight とまったく同じ形のノコギリが出る。
振幅も周期もほぼ同じで、向きだけが逆。**

前日の [2026.09.01 preNightの輝度変動.md] と**同じ手順・同じ指標**で出している。並べて読むこと。

## 2. 測り方

前日と完全に同じ。CR3 の埋め込み全画素JPEGを PIL の `draft` で 1/4 に落として輝度(L)を取り、
256bin ヒストグラムから **中央値**（`histMedian` と同じ手順→ sRGB を外してリニア化）と
**平均**（各binをリニア化してから加重平均）、**飽和率**（sRGB 250以上の画素の割合）を出す。

**注意: センサーRAWではなくカメラ現像後のJPEG。** 露出1目盛りに対して画像は
**1.33倍**に増幅されて見える（実測 n=38、0.84〜1.97倍）。前日夕方は 1.28倍だったので
ほぼ同じ。段数を語るときはこの倍率で割ること。

被写体側の明るさは `scene[段] = log2(Y) + log2(F^2/ss) - log2(ISO/100)`。

**前日からの変更点が1つある。** 妥当なコマの条件を「飽和率2%未満」から
**「中央値そのものが飽和していない(med < 0.85)」**に変えた。今朝は日中の空が明るく
**全242コマが飽和率2%超**で、前日の条件では日中の基準がまったく取れなかったため。
中央値が飛んでいなければ中央値ベースの指標は使える。次回以降もこの条件で揃えること。

## 3. 結果

### 3.1 コマ間の明るさ変化

画像リニア輝度・中央値ベース。

|---|---|---|---|
| 日中 05:20〜06:16 | 0.032段 | 0.079 | +0.09 / −0.45段 |
| **postNight 前半 04:14〜04:45** | **0.092段** | 0.183 | +0.57 / −0.57段 |
| **postNight 後半 04:45〜05:15** | **0.163段** | 0.202 | +0.22 / −0.44段 |
| postNight 全体 | 0.127段 | 0.192 | +0.57 / −0.57段 |

**postNight は日中の 4.0倍** ぶれている（前日夕方の preNight は 2.7倍）。

### 3.2 形はノコギリ（向きが逆）

241コマを分けると、前日と同じようにきれいに分かれる。

* 露出が動いたコマ（38回）… **−0.374段の落ち込み**（|平均| 0.433段、最大 −0.57段）
* 露出そのままのコマ（203回）… **+0.070段/コマ でせり上がり**
* 1山の長さ … 平均 7.2コマ = **107秒**、山の振れ 平均 0.43段 / 最大 1.09段

夕方は「じりじり暗くなって1目盛りで跳ね上がる」、朝は「じりじり明るくなって1目盛りで落ちる」。
**同じ現象の鏡像**である。

いちばん長い山（04:32:14〜04:37:59、**24コマ=5分45秒で +1.09段**）:

```
04:31:59  ISO320  0.05382  +0.04
04:32:14  ISO250  0.03755  -0.52   ← 1目盛り絞る
04:32:59  ISO250  0.04111  +0.04
04:33:59  ISO250  0.04667  +0.04
04:34:59  ISO250  0.05311  +0.05
04:35:59  ISO250  0.06078  +0.05
04:36:59  ISO250  0.06919  +0.04

落ち込みが −0.49段（実露出換算 0.32段 = 1/3段グリッド）なのに対し、
山の登りが +1.09段。**1目盛りでは戻し切れないところまで溜めてから動いている。**

### 3.3 入口の急降下と行き過ぎ（朝だけに出る）

Nightscape → postNight の切り替わりで、夜間の固定露出から測光値へ**一気に降りる**。

```

* **2分間、毎コマ約0.5段ずつ落ち続ける。** タイムラプスでは急激な暗転として出る。
* しかも **ISO250 まで下げてから 320 へ戻している**。1目盛りの行き過ぎ。
* この区間のいちばん暗いコマが **04:17:14 med 0.02215（日中比 −3.21段）**で、
  postNight 全体の最暗値もここ。つまり**最暗点は空の暗さではなく行き過ぎで作られている**。

夕方の preNight には出ない。夕方は日中の自動露出から連続して入るのに対し、
朝は**夜間の固定露出から入る**ため、入口で必ずこの落差を埋めることになる。

## 4. 原因（前日と同一）

1. **露出の刻みが1/3段。** ノコギリの高さの下限を決める。
2. **デッドバンド 0.3段。** 0.3段ずれるまで動かさないので、必ず「0.3段せり上がってから0.33段落ちる」。
3. **4コマ間引き。** ss=8秒の暗所なので実写サムネイル測光＋4コマ間引きが効き、測光は60秒に1回。
   補正の上限が 0.33段/分 になる。
4. **移動平均3サンプル。** 間引き後は3分ぶんの平均になり、実質1.5分の遅れ。

いちばん長い山（3.2節）の直前の測光値と移動平均を突き合わせると、前日とまったく同じ形になる。

| 測光コマ | 生Y | 狙いev0 | 生の誤差 | 移動平均3の誤差 | 動作 |
|---|---|---|---|---|---|
| fr=263 (04:34:40) | 0.0607 | 0.0600 | +0.02段 | +0.02段 | 帯の中・据え置き |
| fr=267 (04:35:40) | 0.0688 | 0.0600 | +0.20段 | +0.10段 | 据え置き |
| fr=271 (04:36:40) | 0.0788 | 0.0600 | **+0.39段** | +0.21段 | **帯の中と判定・据え置き** |
| fr=275 (04:37:40) | 0.0888 | 0.0600 | +0.57段 | +0.39段 | ここで初めて1目盛り |

fr=271 の時点で生の値は 0.39段 外れていたが、移動平均では 0.21段 でデッドバンド 0.3段 の
中に入り、1分間見送られている。**前日 fr=508 で見たのと同じ挙動。**

朝に固有なのは 3.3節の**入口の急降下と1目盛りの行き過ぎ**。

## 6. 次回に見ること

* 光害の少ない場所（空が最後まで落ち続ける／上がり続ける条件）でのノコギリ振幅
* **入口の行き過ぎ（3.3節）が毎回出るか。** 朝だけの現象なので、朝をもう1回は要る
* 曇天/晴天の差（空が均一だと中央値が安定するはず）
* デッドバンドや移動平均を変えた場合の前後比較

**測り方（2章）は変えないこと。** ただし妥当コマの条件は `med < 0.85` に統一した（2章参照）。
トーンカーブの倍率（1.28〜1.33）は機種で変わるので、機種を変えたら測り直す。
