# 2026.09.04 R50V の preNight / postNight の輝度変動

2026-09-04 の朝と夕の通し(EOS R50 V・スマホ直結)の実画像から、移行帯のコマ間の
明るさの安定性を調べた記録。**結論: 露出制御に大きな問題は見当たらない。**
移行帯の平坦部は傾きがほぼゼロ、コマ間のばらつきも 1 目盛りの半分以下に収まる。

先行する [2026.09.01 preNightの輝度変動.md] / [2026.09.02 postNightの輝度変動.md]
(EOS R10) と**同じ手順・同じ指標**で出している。並べて読むこと。

**先行メモの記述を 2 点訂正している(6 章・7 章)。**

## 2. 測り方

先行メモと完全に同じ。CR3 の埋め込み全画素JPEGを PIL の `draft` で 1/4 に落として輝度(L)を
取り、256bin ヒストグラムから **中央値**(`histMedian` と同じ手順 → sRGB を外してリニア化)と
**平均**(各binをリニア化してから加重平均)、**飽和率**(sRGB 250以上の画素の割合)を出す。
妥当なコマの条件も同じ `0 < 中央値 < 0.85`。

    python an_shot_linear.py "_picture/2026.09.04(夕)/R50V" img_0904e.tsv
    python an_shot_log.py _retrieved_logs/hg_2026-09-04.log.txt 2026-09-04 evening log_0904e.tsv
    python an_shot_report.py img_0904e.tsv log_0904e.tsv 2026-09-04 joined_0904e.tsv

**露出1目盛りに対する画像の応答倍率**(現像トーンカーブぶん)は機種で変わるので測り直した。

| | 応答倍率 |
|---|---|
| R50V 夕 | **1.40倍** (n=24, 1.01〜1.70) |
| R50V 朝 | **1.34倍** (n=26, 0.98〜1.67) |
| R10 夕(9/1) | 1.29倍 |
| R10 朝(9/2) | 1.33倍 |

以下、**「実効」と書いた段数はこの倍率で割った値**。倍率を掛けたままの値は「画像段」と書く。

### 注意: R50V は平均(Ymean)が使えない

飽和した画素の割合が R10 と桁違いに多い。

| | 日中 | 移行帯 | 夜間 |
|---|---|---|---|
| R50V 夕 | 31.9% | 8.0% | 34.1% |
| R50V 朝 | 33.8% | 19.4% | 13.6% |
| R10 夕(9/1) | — | 1.2% | — |

同じ構図なので機種のJPEG現像の差。上が張り付くため **平均の \|Δ\| は中央値の 1/5** に潰れる
(夕 0.020段 対 0.095段)。**R50V では中央値だけを使うこと。**

## 3. 結果: リニア輝度の動き

### 3.1 全体の推移(画像中央値・日中を 0段 とする)

**夕 preNight** … 0.107(18:05) → 0.038(18:28) まで一気に落ち、以降 **0.038〜0.050 で横ばい**。
最暗は 19:04 の 0.030(日中比 −2.17段)。

**朝 postNight** … 0.062(04:16) → 0.038(04:45 最暗、−2.42段) → **0.198**(05:16)。
前半は横ばい、後半で立ち上がる。

狙い(ev0 シグモイド)は太陽高度 −5°付近から 0.060 に張り付くので、**平均としては設計どおり**。
狙いとの差は 夕 −0.32〜+0.07段、朝 −0.26〜+0.56段。

### 3.2 平坦部に偏りはない ← 今回いちばん見たかったところ

狙いが 0.06 に張り付いている区間だけを取り、つなぎ目の寄せ(3.4)は除いた。実効段数。

| | 傾き | 前半−後半 | σ | 幅 | 隣接コマ最大 |
|---|---|---|---|---|---|
| **R50V 夕 18:25-19:04** | **+0.007段/分** | −0.17段 | **0.13段** | 0.58段 | 0.40段 |
| **R50V 朝 04:16-04:56** | **−0.001段/分** | **−0.01段** | **0.17段** | 0.86段 | 0.42段 |
| 参考 夜間(固定露出) 夕 | −0.001段/分 | +0.08段 | 0.07段 | 0.33段 | 0.06段 |
| 参考 夜間(固定露出) 朝 | +0.003段/分 | −0.07段 | 0.03段 | 0.15段 | 0.01段 |

* **朝は完全に平ら**。40分で −0.04段、前半と後半の差 0.01段。測りようがない
* **夕はごくわずかに後半が明るい**が 0.17段。1目盛り(0.33段)の半分で、見て分かる差ではない
* ばらつき σ 0.13〜0.17段。**固定露出の 0.03〜0.07段 に対し、自動制御が足している揺らぎは 0.1段ほど**

目視の印象(「明るさは一定で、色合いだけが変わる」)と数値は一致している。**隣り合うコマの差は
平均 0.07段・最大 0.40段**で、タイムラプスで見えるのは隣接コマの差だけなので気づかない。

### 3.3 コマ間の明るさ変化(道具の出力・画像段)

| | \|Δ\|平均 | RMS | 最大 | 前半 | 後半 | 日中 |
|---|---|---|---|---|---|---|
| 夕 preNight | 0.095段 | 0.168 | +0.55/−0.56 | 0.137 | 0.052 | 0.032 |
| 朝 postNight | 0.103段 | 0.163 | +0.13/−0.56 | 0.062 | 0.143 | 0.057 |

**移行帯の「明るい側に近いほう」が荒れる**のは R10 と同じ形(夕は前半、朝は後半)。空の変化が
そこで最も速いため。

### 3.4 ノコギリの形は R10 と同じ

| | 露出が動いたコマ | 露出そのままのコマ | 山 |
|---|---|---|---|
| 夕 | 24回 **+0.462段** | 219回 −0.045段/コマ | 20本 11.9コマ(179秒) 振れ 平均0.50 最大1.12段 |
| 朝 | 26回 **−0.445段** | 218回 +0.061段/コマ | 22本 10.9コマ(164秒) 振れ 平均0.61 最大1.40段 |

夕は「じりじり暗くなって1目盛りで跳ね上がる」、朝はその鏡像。**振れの最大は朝の +1.40段**で、
05:00 前後に 1.0段超の山が 5 本続く。実際の並び(朝・画像中央値と生の測光誤差):

```
05:00:16 ss1.3  0.056  測光誤差 +0.02段
05:01:01 ss1.3  0.072       +0.35段   ← 0.3段は超えている
05:01:31 ss1.3  0.085       +0.56段
05:02:16 ss1.3  0.107       +0.88段
05:02:31 ss1.3  0.115       +0.98段
05:02:46 ss1    0.085       ← ここでやっと1目盛り
```

12コマ(3分)で +1.36段 ずり上がってから落とす。**測光は上昇をずっと見えている。**
帯が ±0.5段(7章)で、そこに移動平均5の遅れ(約75秒)が乗るとこうなる。
ただし1コマあたりに直すと 0.1段 なので、見た目には現れない。

## 4. R10 との比較

### 4.1 同じ時間帯で切ると、ほぼ同じ

| 18:09〜18:34(**両方とも毎コマ測光**) | σ | \|Δ\|平均 | 露出変更 | 空の変化 |
|---|---|---|---|---|
| R10 9/1(LV測光) | 0.20段 | 0.124段 | 18回 | −0.222段/分 |
| R50V 9/4(サムネイル測光) | 0.19段 | 0.103段 | 15回 | −0.175段/分 |

| 18:36〜19:04 | σ | \|Δ\|平均 | 露出変更 | 空の変化 |
|---|---|---|---|---|
| R10 9/1(**4コマ間引き**) | 0.14段 | 0.046段 | 6回 | −0.038段/分 |
| R50V 9/4(毎コマ) | 0.13段 | 0.021段 | 1回 | −0.017段/分 |

**差は無い。** 残る違いは空の変化の速さ(R10 の日のほうが 2〜3割速く暗くなった)でほぼ説明がつく。

### 4.2 間引きの害は、このデータでは測れていない

R10 の間引きが始まった 18:34:50 は、**この場所で空が暗くならなくなる時刻(18:45頃)の直前**
だった。間引きが効いている区間は空が −0.038段/分 とほぼ止まっており、1分に1回の測光でも
間に合う。**したがって「間引かなければ良くなるか」は今回のデータからは判定できない。**

ただし手掛かりはある。9/1 の最悪の山(**13コマ・3分15秒で −1.28段**)は **18:34:45**、
つまり**間引きへ切り替わった瞬間**に起きている。1回だけだが「速く動いている最中に間引きへ
切り替わると崩れる」ことを示唆する。

**確かめ方**: R10 の所持カメラ設定で「ライブビューで測光する」を切る(R50V と同じ
サムネイル1本・間引き無しになる)。同じ場所・同じ時間帯で1本撮って 4.1 と同じ表を作る。
R50V が毎コマ測光のまま −0.175段/分 の区間を σ0.19段 で通せているので、比較の相手になる。

## 5. つなぎ目の段差は夜間の固定露出しだい

移行帯と夜間のつなぎ目では、毎コマ1目盛りずつ夜間の固定露出へ寄せる(4128469)。
**その段差の大きさは制御の善し悪しではなく、夜間の固定露出(ユーザー設定)で決まる。**

| | 夜間の画像中央値 | 移行帯の狙い(0.06)との差 | つなぎ目 |
|---|---|---|---|
| **R50V 9/4 朝** | **0.062** | ほぼ一致 | **段差なし**(04:16 で 0.0622→0.0624 と連続) |
| R50V 9/4 夕 | 0.246 | +2.0段 | +3.0段を2分弱で寄せる |
| R10 9/1 夕 | 0.785 | +3.7段 | +3.8段を2分15秒で寄せる |
| R10 9/2 朝 | 0.356 | +2.6段 | −4.0段を1分45秒で寄せる |

R50V 夕のつなぎ目(1コマ 0.5段ずつ、2分で3段)は**ここだけは見て分かるはず**。
気になるなら夜間の固定露出を暗めにすれば段差は縮む。

**先行メモの数字にはこの寄せが混ざっている。** 区間を切るときは必ず除くこと。
今回いったん含めて計算し、R10 の σ が 0.30〜0.41段、幅が 2.5〜3.0段 と出て
「R50V の方が明らかに平ら」と誤った結論を出しかけた。除けば 4.1 のとおり差は無い。

## 7. 訂正(2): デッドバンドの正体は 0.3段ではなく 1.0段

9/1 のメモは原因の 2 番目を「**デッドバンド 0.3段**」としていたが、**これは誤り**。

`preNight` / `postNight` は**夜間の窓**であり、夜間の撮影制御方法は `hysteresis=0`
すなわち**全体設定**を使う(`captureRunner.cpp` の `effHyst`)。全体設定は
**1.0段 / 移動平均5**。0.3段/3 が入っているのは `factoryCcmSet` の朝日と夕日だけで、
今回の計画では夕日・朝日を使っていない。

実測でも裏が取れた。**露出を動かす直前の生の測光誤差の中央値**:

| | 中央 | 平均 | 範囲 |
|---|---|---|---|
| R50V 9/4 夕 | **0.49段** | 0.47 | 0.20〜0.82 |
| R50V 9/4 朝 | 0.53段 | 0.76 | 0.36〜2.03 |
| **R10 9/1 夕** | **0.54段** | 0.59 | 0.02〜1.08 |
| R10 9/2 朝 | 1.25段 | 1.27 | 0.45〜2.76 |

**帯 1.0段 の半分(±0.5段)そのもの。** R10 のデータを同じ方法で測り直しても 0.54段 なので、
当時から 1.0段 だったことになる。R10 9/2 朝が 1.25段 と大きいのは、4コマ間引き＋移動平均で
判断が遅れるため。

**ノコギリの振幅を決めているのは ±0.5段の帯**であり、メモが書いた 0.3段 ではない。
逆に言えば **帯を狭めれば直接効く**。ただし今回の結論は「大きな問題なし」なので、
狭める必要があるかは別途判断する。

## 8. 道具の変更(突き合わせだけ)

**カメラ内時計がスマホとずれていると突き合わせが成立しない。**

| | ずれ |
|---|---|
| R50V | **+56〜57秒**(カメラが進んでいる) |
| R10 | −14秒 |

±3秒許容の時刻突き合わせでは 1320コマ中 130コマしか一致しなかった。15秒周期なので
「何秒ずらすと一番合うか」を探すと 15秒の倍数がすべて同点になり、時刻だけでは決められない。

そこで `an_shot_report.py` を **「コマ数が一致するときは順番で対応づける」** ように変更した。
撮影は1コマ1ファイルで欠けも重複も無いので、これが最も確実。対応が正しいことは
**ISO/ss/F の一致で検算**する(今回いずれも食い違い 0 コマ)。数が合わない場合は従来の
時刻突き合わせに戻る。**指標の計算は何も変えていない**(R10 9/1 で再計算しても従来どおり)。
